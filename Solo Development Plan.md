## Detailed Milestone Breakdown
* Milestone 1: Core Physics & Touch Driving (Weeks 1–2)
	Focus: Validate that driving a momentum-based shopping cart with a mobile virtual joystick feels fun without any combat active 4, 17.
	Key Tasks:
	- Implement touch joystick input for steering, acceleration, braking, and drifting 4.
	- Tune momentum, wheel friction, turn radius, and high-speed drift angles 5, 18.
	- Implement physical ramming damage based on collision speed 19, 20.
- Milestone 2: Combat & Intoxication Mechanics (Weeks 3–4)
	Focus: Combine mobile auto-shooting with the core risk-versus-reward intoxication curve 3, 9.
	Key Tasks:
	- Build an auto-aim system that targets the nearest threat 6, 7.
	- Implement 3 enemy archetypes: Chasers (melee pressure), Ranged Spitters (forces movement), and Heavy Blockers (path obstacles) 8, 21.
	- Build the 1-tap Drink Beer mechanic: drinking increases fire rate and damage but progressively degrades wheel traction and steering response 9, 22.
- Milestone 3: In-Run Progression & UI (Weeks 5–6)
	Focus: Turn the combat loop into a structured 10-minute run 10, 11.
	Key Tasks:
	- Create an XP collection and leveling system 12.
	- Build a clean mobile HUD displaying Cart Health, Intoxication Level, Beer Count, and XP Bar 23.
	- Implement a pool of 8–10 in-run upgrades (e.g., Double Shot, Spiked Bumper, Greased Wheels, Functional Alcoholic) 13.
- Milestone 4: Vertical Slice & Pitch Prep (Weeks 7–8)
	Focus: Assemble a complete, polished 10-minute demo suitable for publisher pitching and video recording 1, 14, 16.
	Key Tasks:
	- Build 1 Supermarket arena level containing open spaces, narrow aisle chokepoints, destructibles, and ramps 14, 15.
	- Implement 1 multi-phase boss fight (The Store Manager) 16.
	- Add sound effects (engine/wheels, beer opening, explosions) and screen juice/VFX 1.
